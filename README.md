# Descargas DeliPOS Android

Este repositorio publica únicamente las APK beta de DeliPOS para terminales Android.

El código fuente se mantiene en un repositorio privado separado.

## Instalar una beta

1. Abre la sección [Releases](../../releases).
2. Descarga la APK correspondiente a tu terminal: **Mesero**, **Caja** o **KDS**.
3. En Android, permite la instalación desde la aplicación con la que descargaste el archivo si el sistema lo solicita.
4. Instala la APK. Las actualizaciones conservan el mismo paquete por perfil.

Cada release incluye el número de versión para facilitar el soporte técnico.
